- Reads the **Excel file** into a Pandas DataFrame.

---

### **3️⃣ Checking for Missing Values**  
```python
dataset.isnull().sum()
```
- Counts **total missing values** per column.

---

### **4️⃣ Filling Missing Values with a Fixed Number (Not Recommended)**  
```python
dataset.fillna(10).head(10)
```
- Replaces all **NaN values** with `10`.  
- **Not a proper approach** because numerical values don’t always make sense in categorical columns.

---

### **5️⃣ Checking Data Types for Better Filling**  
```python
dataset.info()
```
- Displays **data types** of each column.  
- Helps decide appropriate filling strategies.

---

### **6️⃣ Filling Methods**
#### **🔵 Backward Fill (bfill) - Fill with Next Value in Column**
```python
dataset.fillna(method='bfill')
```
- **Fills missing values** with the next available value in the **same column**.  
- Useful for **time-series data**.

#### **🟢 Forward Fill (ffill) - Fill with Previous Value in Column**
```python
dataset.fillna(method='ffill')
```
- **Fills missing values** with the previous available value in the **same column**.  
- Preserves trends in **time-series data**.

#### **🟠 Column-wise Filling (Row-wise Propagation)**
```python
dataset.fillna(method='ffill', axis=1)
dataset.fillna(method='bfill', axis=1)
```
- **`axis=1`** → Moves **left to right** in a row to fill missing values.  
- Used when **data across columns** is related.

---

### **7️⃣ Filling Categorical Data with Mode (Most Repeated Value)**
#### **🔴 Getting Mode (Most Frequent Value)**
```python
dataset['CatD'].mode()[0]  
```
- Finds the **most repeated value** in the `'CatD'` column.

#### **🟣 Filling Categorical Data with Mode**
```python
dataset['CatD'].fillna(dataset['CatD'].mode()[0])
```
- Fills missing values with **most repeated category**.

---

### **8️⃣ Filling Missing Values in All Categorical Columns**
```python
# Select categorical columns
dataset.select_dtypes(include='object')

# Count missing values in categorical columns
dataset.select_dtypes(include='object').isnull().sum()

# Get names of categorical columns
dataset.select_dtypes(include='object').columns

# Fill missing values in each categorical column using mode
for col in dataset.select_dtypes(include='object').columns:
    dataset[col].fillna(dataset[col].mode()[0], inplace=True)
```
- Selects **all categorical columns**.  
- Fills missing values with the **most repeated value (mode)**.  
- **Loop ensures all categorical columns** are filled properly.

---

### **9️⃣ Performing All Operations on Real Data**
```python
dataset = pd.read_excel("C:/Users/junai/Desktop/coding/ML/catg_data.xlsx")
```
- Reads the dataset again to apply filling methods properly.

#### **✅ Using Both Forward & Backward Fill**
```python
dataset = dataset.bfill()
dataset = dataset.ffill()
```
- **First uses `bfill`** → fills missing values with the **next available value**.  
- **Then `ffill`** → fills remaining missing values with **previous values**.

#### **✅ Row-wise Forward & Backward Fill**
```python
dataset = dataset.T.ffill().T  # Fill row-wise (transpose, fill, then revert)
dataset = dataset.T.bfill().T  # Fill row-wise (backward)
```
- **Ensures NaN values across rows** are filled properly.

#### **✅ Filling Categorical Columns with Mode**
```python
for col in dataset.select_dtypes(include='object').columns:
    dataset[col] = dataset[col].fillna(dataset[col].mode().iloc[0])  
```
- Uses **`.iloc[0]`** to get mode correctly and avoid warnings.  

---

### **🔟 Fixing Data Type Issues**


📌 ML Notes - One Hot Encoding (OHE) 

## **Introduction**  
Today, I learned how to convert categorical data into numerical data using **One Hot Encoding (OHE)**. This is useful for ML models since they work better with numerical values.  

---

## **1️⃣ Understanding One Hot Encoding (OHE)**  
- **Categorical Data** (e.g., "Male"/"Female") needs to be converted into numerical form for ML models.  
- **One Hot Encoding** converts categories into separate columns with **binary values (0 or 1)**.  

### **Example:**
| Gender  | Gender_Male | Gender_Female |
|---------|------------|--------------|
| Male    | 1          | 0            |
| Female  | 0          | 1            |

There are **2 ways** to perform **One Hot Encoding** in Python:  
1. `pd.get_dummies()` (Pandas method)  
2. `OneHotEncoder` (from `sklearn.preprocessing`)  

---

## **2️⃣ Importing Required Libraries**  
```python
import pandas as pd
```
- `pandas`: Used to handle and manipulate datasets.  

---

## **3️⃣ Loading the Dataset**  
```python
dataset = pd.read_excel(r"C:\Users\junai\Desktop\coding\ML\gender_cat_data.xlsx")
dataset.head(10)
```
- `pd.read_excel()`: Reads an Excel file into a Pandas DataFrame.  
- `.head(10)`: Displays the first 10 rows of the dataset.  

---

## **4️⃣ Selecting Categorical Columns for Encoding**  
```python
en_data = dataset[["Gender", "Married"]]
en_data
```
- Extracts the **"Gender"** and **"Married"** columns for encoding.  

---

## **5️⃣ One Hot Encoding Using `pd.get_dummies()`**  
```python
pd.get_dummies(en_data)
```
- Converts categorical columns into multiple binary columns.  
- Example Output:
  | Gender_Male | Gender_Female | Married_Yes | Married_No |
  |------------|--------------|------------|------------|
  | 1          | 0            | 0          | 1          |
  | 0          | 1            | 1          | 0          |

```python
pd.get_dummies(en_data).info()
```
- `.info()`: Checks the data types.  
- The new columns are created as **Boolean values (True/False)**, which need to be converted to **numerical (0/1)**.

---

## **6️⃣ One Hot Encoding Using `OneHotEncoder` (sklearn)**  
```python
from sklearn.preprocessing import OneHotEncoder
```
- `OneHotEncoder` is imported from `sklearn.preprocessing`.  

### **Fitting and Transforming Data**  
```python
ohe = OneHotEncoder()
ohe.fit_transform(en_data)
```
- `.fit_transform(en_data)`:  
  - **fit()**: Learns the unique values in the categorical columns.  
  - **transform()**: Converts them into **sparse matrix format** (saves memory).  

```python
# Converting Sparse Matrix to NumPy Array
ar = ohe.fit_transform(en_data).toarray()
```
- **Converts the sparse matrix** into a **NumPy array** for easier use.  

```python
pd.DataFrame(ar, columns=["Gender_Female", "Gender_Male", "Married_No", "Married_Yes"])
```
- Converts the array into a **Pandas DataFrame** with proper column names.  

---

## **7️⃣ Dropping Unnecessary Columns (`drop='first'`)**  
```python
ohe = OneHotEncoder(drop='first')
ohe.fit_transform(en_data)
ar = ohe.fit_transform(en_data).toarray()
pd.DataFrame(ar, columns=["Gender_Male", "Married_Yes"])
```
- `drop='first'`: Removes the first column of each category to **avoid redundancy**.  
- **Example Output:**
  | Gender_Male | Married_Yes |
  |------------|------------|
  | 1          | 0          |
  | 0          | 1          |

---

## **📌 Summary of What I Learned Today**  
- **One Hot Encoding** is used to convert categorical data into numerical form.  
- **Two ways to apply OHE**: `pd.get_dummies()` and `OneHotEncoder`.  
- **Sparse Matrix vs. Dense Format**:  
  - `OneHotEncoder` returns a **sparse matrix** (efficient for memory).  
  - It must be **converted to an array** and then to a DataFrame for easy handling.  
- **Dropping the first category (`drop='first'`)** reduces unnecessary columns.  

### **💡 Why is this Important?**  
- ML models **cannot process categorical data** directly.  
- One Hot Encoding **ensures numerical representation** without introducing bias.  
- Reducing redundant columns **prevents multicollinearity** in models.

# 📊 Outlier Detection & Removal - Summary Notes

## 🧠 What is an Outlier?

An **outlier** is a data point that lies far outside the expected range in a dataset.
It can:

* Distort statistical measures like **mean**.
* Introduce **noise** in machine learning models.
* Lead to **inaccurate predictions**.

---

## 🎯 Example: Impact on Mean

* **Without Outlier**:

```python
data = {5, 5, 6, 4, 6, 4, 6, 5 , 8 , 5, 8, 9, 5, 4}
mean = sum(data)/len(data)
```

* **With Outlier (100)**:

```python
data = {5, 5, 6, 4, 6, 4, 6, 5 , 100 , 5, 8, 9, 5, 4}
mean = sum(data)/len(data)  # Result significantly skewed
```

---

## 🛠️ How to Handle Outliers

1. **Outlier Detection**
2. **Outlier Removal**

---

## 📦 Dataset Overview

Used Yahoo stock data: `yahoo_data.xlsx`

### Tools:

* `pandas`, `seaborn`, `matplotlib`

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

dataset = pd.read_excel("yahoo_data.xlsx")
```

---

## 📌 Outlier Detection Techniques

### 1. **Box Plot**

```python
sns.boxplot(x="Volume", data=dataset)
plt.show()
```

* Shows outliers clearly beyond whiskers.

### 2. **Distribution Plot**

```python
sns.distplot(dataset["Adj Close**"])
plt.show()
```

* Long tail on the curve indicates possible outliers.

---

## 🔍 Outlier Removal Techniques

### ✅ 1. IQR Method (Interquartile Range)

```python
Q1 = dataset["Volume"].quantile(0.25)
Q3 = dataset["Volume"].quantile(0.75)
IQR = Q3 - Q1

min_range = Q1 - (1.5 * IQR)
max_range = Q3 + (1.5 * IQR)

new_dataset = dataset[(dataset["Volume"] >= min_range) & (dataset["Volume"] <= max_range)]
```

**Result**: 55 outliers removed from `Volume`.

---

### ✅ 2. Z-Score Method

#### Method 1: Manual Z-score Range

```python
mean = dataset["Adj Close**"].mean()
std = dataset["Adj Close**"].std()

min_range = mean - (3 * std)
max_range = mean + (3 * std)

new_dataset2 = dataset[dataset["Adj Close**"] <= max_range]
```

**Result**: 2 outliers removed from `Adj Close**`.

#### Method 2: Using Z-score Formula

```python
dataset["z_score"] = (dataset["Adj Close**"] - dataset["Adj Close**"].mean()) / dataset["Adj Close**"].std()
filtered = dataset[dataset["z_score"] < 3]
```

---

## ✅ Observations

* Outliers were found in `Volume` and `Adj Close**`.
* IQR and Z-Score both effectively cleaned the data.
* Box plots and distribution plots are **great visual tools** for outlier detection.

Feature Scaling

## 💡 What is Feature Scaling?

Feature Scaling is the technique of **bringing all features to a similar scale**, especially when there are vast differences in magnitude.

### 🔍 Why It’s Important:

* Prevents **features with large values** from dominating others during model training.
* Ensures **fair treatment** of each feature.
* Maintains **original nature** of the data.
* Does **not remove outliers**, but reduces their **impact** by minimizing magnitude.

---

## 🧰 Types of Feature Scaling

### 1. **Standardization (Z-score Normalization)**

Transforms the data to have a **mean of 0** and **standard deviation of 1**.

#### 📌 Formula:

$$
X_{\text{new}} = \frac{X_i - \text{mean}(X)}{\text{std}(X)}
$$

* Makes data **centered** around 0
* Suitable for algorithms assuming normally distributed data (e.g. Logistic Regression, SVM)

---

### 📈 Example – Standardization of `Adj Close**`

```python
from sklearn.preprocessing import StandardScaler

ss = StandardScaler()
ss.fit(dataset[["Adj Close**"]])
dataset["Adj Close**_ss"] = ss.transform(dataset[["Adj Close**"]])
```

#### 🔍 Before vs After:

* Before: Skewed with large range
* After: Compressed, but distribution shape remains similar

```python
plt.subplot(1,2,1)
sns.distplot(dataset["Adj Close**"])
plt.title("Before")

plt.subplot(1,2,2)
sns.distplot(dataset["Adj Close**_ss"])
plt.title("After")
plt.show()
```

---

### 2. **Normalization (Min-Max Scaling)**

Rescales features to a **fixed range \[0, 1]**

#### 📌 Formula:

$$
X_{\text{new}} = \frac{X_i - \min(X)}{\max(X) - \min(X)}
$$

* Maintains **original distribution**
* Useful in models sensitive to feature magnitudes (e.g. KNN, Neural Networks)

---

### 📈 Example – Min-Max Scaling on `Volume`

```python
from sklearn.preprocessing import MinMaxScaler

mms = MinMaxScaler()
mms.fit(dataset[["Volume"]])
dataset["Volume_mms"] = mms.transform(dataset[["Volume"]])
```

#### 🔍 Before vs After:

* Before: Large values dominating
* After: Rescaled to 0–1 range

```python
plt.subplot(1,2,1)
sns.distplot(dataset["Volume"])
plt.title("Before")

plt.subplot(1,2,2)
sns.distplot(dataset["Volume_mms"])
plt.title("After")
plt.show()
```

---

## ✅ Key Takeaways

| Feature            | Standardization                | Normalization               |
| ------------------ | ------------------------------ | --------------------------- |
| Range              | Mean = 0, Std = 1              | Fixed between \[0, 1]       |
| Distribution       | May be negative or positive    | Always positive             |
| Use Case           | ML models with distance metric | When features vary in scale |
| Effect on Outliers | Reduces impact only            | Doesn't handle directly     |
