## 📘 Supervised Machine Learning

Supervised learning is a type of machine learning where the model is trained on labeled data — the input data and the corresponding correct output.

### Two Main Types:
- **A) Regression Learning** – When the target variable is **continuous**.
- **B) Classification Learning** – When the target variable is **categorical**.

---

## 🔷 A) Regression Analysis

Used when the output variable is **continuous** (e.g., salary, price, temperature, etc.).

### 🔹 1) Linear Regression Algorithms

#### i) Simple Linear Regression
- Involves a **single independent variable**.
- Fits a straight line to the data:  
  `y = mx + c`
- Example: Predicting salary based on years of experience.

#### ii) Multiple Linear Regression
- Involves **multiple independent variables**.
- General form:  
  `y = b0 + b1*x1 + b2*x2 + ... + bn*xn`

#### iii) Lasso Regression
- **L1 regularization** technique.
- Adds a penalty to the model to prevent overfitting by **shrinking coefficients**.
- Can eliminate irrelevant features (feature selection).

#### iv) Ridge Regression
- **L2 regularization** technique.
- Shrinks coefficients but does not eliminate them completely.
- Helps with multicollinearity and improves generalization.

---

### 🔹 2) Non-Linear Regression Algorithms

These algorithms capture complex relationships that a straight line can't.

#### i) Polynomial Regression
- Fits a **curve** to the data using polynomial terms like `x²`, `x³`, etc.
- Useful when data shows a **non-linear trend**.

#### ii) Decision Tree Regression
- Splits the dataset into decision nodes and leaves to make predictions.
- **Non-parametric** and easy to interpret.

#### iii) Random Forest Regression
- An ensemble of multiple decision trees.
- Aggregates output from all trees (average for regression).
- Reduces overfitting and increases accuracy.

#### iv) Support Vector Machine (SVM)
- Originally used for classification but can be adapted for regression (`SVR`).
- Finds a **margin of tolerance** (epsilon) within which predictions are acceptable.

#### v) k-Nearest Neighbour (k-NN)
- Predicts the output based on the **average of k nearest data points**.
- Non-parametric and simple, but sensitive to data scaling.

## 📘 Simple Linear Regression

### ✅ Definition:

Simple Linear Regression is used when there is only **one independent variable (input feature)** to predict a **continuous dependent variable (output)**.

* **Equation used**:

  $$
  y = mx + c
  $$

  where:

  * `x` = independent variable
  * `y` = dependent variable
  * `m` = slope of the line
  * `c` = intercept (bias)

* **Slope Formula**:

  $$
  m = \frac{y2 - y1}{x2 - x1}
  $$

---

## 📘 Multiple Linear Regression

### ✅ **Definition**

* **Multiple Linear Regression** is used when we need to predict **one dependent variable (output)** using **multiple independent variables (inputs)**.
* It assumes a **linear relationship** between the inputs and the output.

---

### 🧮 **Equation**


y = m_1x_1 + m_2x_2 + \dots + m_nx_n + c


* $y$ → predicted output (e.g., Salary)
* $x_1, x_2, ..., x_n$ → input features (e.g., Age, Experience)
* $m_1, m_2, ..., m_n$ → weights/coefficients
* $c$ → intercept

---

   * Use **graphs and correlation**.
2. If **not linear**, perform **feature selection or transformation**.
3. **Split the dataset** into training and test sets.

5. Evaluate model performance using `.score()` or prediction error metrics.

## 📊 **Cost Function – **

### 🔎 What is a Cost Function?

* A formula used to **evaluate model performance** by measuring prediction error.
* The lower the cost, the better the model is at prediction.

---

## 🔢 **Types of Cost Functions**

### 1️⃣ **Regression Cost Functions** (used for continuous outputs)

---

### 🔷 **MSE – Mean Squared Error**

**Formula**:

$$
\text{MSE} = \frac{1}{n} \sum (y_i - \hat{y}_i)^2
$$

✅ **Advantages**:

* Penalizes large errors heavily
* Differentiable and widely used in optimization (like gradient descent)

❌ **Disadvantages**:

* Sensitive to outliers (squared terms exaggerate large differences)

---

### 🔷 **MAE – Mean Absolute Error**

**Formula**:

$$
\text{MAE} = \frac{1}{n} \sum |y_i - \hat{y}_i|
$$

✅ **Advantages**:

* Robust against outliers
* Easy to interpret (error in original units)

❌ **Disadvantages**:

* Not differentiable at 0 (can complicate optimization)
* May not penalize large errors as strongly as MSE

---

### 🔷 **RMSE – Root Mean Squared Error**

**Formula**:

$$
\text{RMSE} = \sqrt{\text{MSE}}
$$

✅ **Advantages**:

* Same unit as output
* Penalizes large errors
* Easier to interpret than MSE

❌ **Disadvantages**:

* Still sensitive to outliers

---

### 🔷 **R² Score – Coefficient of Determination**

**Formula**:

$$
R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}
$$

✅ **Advantages**:

* Shows how well the model explains the variance in output
* Intuitive: 1 = perfect fit, 0 = no fit

❌ **Disadvantages**:

* Can be negative if the model is worse than just predicting the mean
* Not reliable for non-linear models unless adjusted

---

### 2️⃣ **Classification Cost Functions** (used for categories)

---

### 🔷 **Binary Cross-Entropy (Log Loss)**

**Formula**:

$$
- \frac{1}{n} \sum \left[ y \cdot \log(\hat{y}) + (1 - y) \cdot \log(1 - \hat{y}) \right]
$$

✅ **Advantages**:

* Works well for binary classification
* Penalizes confident wrong predictions

❌ **Disadvantages**:

* Not intuitive in interpretation
* Requires careful numerical handling (log(0) issues)

---

### 🔷 **Categorical Cross-Entropy**

Used for multi-class classification.

✅ **Advantages**:

* Works well with softmax output for classification
* Penalizes wrong predictions proportionally to their probability

❌ **Disadvantages**:

* Same as binary — requires stable computation
* Becomes complex with many classes

## 🛡️ **Regularization Techniques**

### 🎯 Goal:

* Reduce **overfitting**
* Improve **generalization**
* Eliminate or reduce irrelevant features

---

### 🔷 What is Overfitting?

When the model learns the noise of training data, causing poor performance on new (test) data. Symptoms:

* High training accuracy
* Low test accuracy

---

### 1️⃣ **Lasso Regularization (L1)**

**Loss Function**:

$$
\text{Loss} = \text{MSE} + \lambda \sum |w|
$$

✅ **Advantages**:

* Performs **feature selection** by shrinking some weights to 0
* Good for sparse datasets with many features

❌ **Disadvantages**:

* Can be unstable when features are correlated
* May drop useful features in some cases

---

### 2️⃣ **Ridge Regularization (L2)**

**Loss Function**:

$$
\text{Loss} = \text{MSE} + \lambda \sum w^2
$$

✅ **Advantages**:

* Reduces overfitting
* Works well with multicollinearity
* Keeps all features, just reduces their impact

❌ **Disadvantages**:

* Doesn’t perform feature elimination
* Less interpretable if many small weights remain

---

### 3️⃣ **ElasticNet (L1 + L2 Combo)**

**Loss Function**:

$$
\text{Loss} = \text{MSE} + \lambda_1 \sum |w| + \lambda_2 \sum w^2
$$

✅ **Advantages**:

* Combines benefits of Lasso and Ridge
* Balances feature selection with model stability

❌ **Disadvantages**:

* Requires tuning of two hyperparameters (`λ1`, `λ2`)

---

Ridge Regularization / L2 Technique – Practical Implementation

## 🔎 What is Ridge?

* **Ridge Regression** (also known as **L2 Regularization**) is a technique used to **reduce overfitting** by penalizing large coefficients.
* It does not remove features (unlike Lasso), but **shrinks them**.
* Ideal when **all features contribute** and **multicollinearity** exists.

---
