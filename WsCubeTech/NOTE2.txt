## 📘 Supervised Machine Learning

Supervised learning is a type of machine learning where the model is trained on labeled data — the input data and the corresponding correct output.

### Two Main Types:
- **A) Regression Learning** – When the target variable is **continuous**.
- **B) Classification Learning** – When the target variable is **categorical**.

---

## 🔷 A) Regression Analysis

Used when the output variable is **continuous** (e.g., salary, price, temperature, etc.).

### 🔹 1) Linear Regression Algorithms

#### i) Simple Linear Regression
- Involves a **single independent variable**.
- Fits a straight line to the data:  
  `y = mx + c`
- Example: Predicting salary based on years of experience.

#### ii) Multiple Linear Regression
- Involves **multiple independent variables**.
- General form:  
  `y = b0 + b1*x1 + b2*x2 + ... + bn*xn`

#### iii) Lasso Regression
- **L1 regularization** technique.
- Adds a penalty to the model to prevent overfitting by **shrinking coefficients**.
- Can eliminate irrelevant features (feature selection).

#### iv) Ridge Regression
- **L2 regularization** technique.
- Shrinks coefficients but does not eliminate them completely.
- Helps with multicollinearity and improves generalization.

---

### 🔹 2) Non-Linear Regression Algorithms

These algorithms capture complex relationships that a straight line can't.

#### i) Polynomial Regression
- Fits a **curve** to the data using polynomial terms like `x²`, `x³`, etc.
- Useful when data shows a **non-linear trend**.

#### ii) Decision Tree Regression
- Splits the dataset into decision nodes and leaves to make predictions.
- **Non-parametric** and easy to interpret.

#### iii) Random Forest Regression
- An ensemble of multiple decision trees.
- Aggregates output from all trees (average for regression).
- Reduces overfitting and increases accuracy.

#### iv) Support Vector Machine (SVM)
- Originally used for classification but can be adapted for regression (`SVR`).
- Finds a **margin of tolerance** (epsilon) within which predictions are acceptable.

#### v) k-Nearest Neighbour (k-NN)
- Predicts the output based on the **average of k nearest data points**.
- Non-parametric and simple, but sensitive to data scaling.

## 📘 Simple Linear Regression

### ✅ Definition:

Simple Linear Regression is used when there is only **one independent variable (input feature)** to predict a **continuous dependent variable (output)**.

* **Equation used**:

  $$
  y = mx + c
  $$

  where:

  * `x` = independent variable
  * `y` = dependent variable
  * `m` = slope of the line
  * `c` = intercept (bias)

* **Slope Formula**:

  $$
  m = \frac{y2 - y1}{x2 - x1}
  $$

---

## 🧪 Step-by-Step Implementation

### 1. **Import Libraries**

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
```

---

### 2. **Load the Dataset**

```python
dataset = pd.read_csv("student_placements.csv")
dataset.head()
```

---

### 3. **Check for Null Values**

```python
dataset.isnull().sum()
```

---

### 4. **Visualize Linearity**

```python
sns.scatterplot(x="CGPA", y="Package(LPA)", data=dataset)
plt.show()
```

✅ **Observation**: The graph shows an upward trend → Indicates **positive linearity** between CGPA and Package.

---

### 5. **Define X and Y**

```python
x = dataset[["CGPA"]]  # Independent variable (2D)
y = dataset["Package(LPA)"]  # Dependent variable (1D)
```

---

### 6. **Split Data into Train & Test Sets**

```python
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=42)
```

* Use different `random_state` values (e.g., 30–70) to explore best splits.

---

### 7. **Train the Model**

```python
lr = LinearRegression()
lr.fit(x_train, y_train)
```

---

### 8. **Model Accuracy**

```python
lr.score(x_test, y_test)  # R² Score, e.g., 0.89 = 89% accuracy
```

---

### 9. **Make Predictions**

```python
lr.predict([[7.00]])  # Predict package for CGPA = 7.00
```

---

### 10. **Get Coefficients**

```python
lr.coef_       # m (slope)
lr.intercept_  # c (intercept)
```

Use these to understand the learned linear equation:

```python
y = m * x + c
```

Example:
If `m = 2.79` and `c = -13.86`, then:

```python
y = 2.79 * 7 + (-13.86) ≈ 5.67 LPA
```

---

### 11. **Visualize Prediction Line**

```python
y_pred = lr.predict(x)

sns.scatterplot(x="CGPA", y="Package(LPA)", data=dataset)
plt.plot(dataset["CGPA"], y_pred, color="red")
plt.legend(["Prediction Line", "Original Data"])
plt.show()
```

---

✅ **Summary**:

* Simple Linear Regression works well when the relation between X and Y is **linearly increasing or decreasing**.
* It is **interpretable**, **easy to implement**, and forms the basis for more complex regressions.

## 📘 Multiple Linear Regression

### ✅ **Definition**

* **Multiple Linear Regression** is used when we need to predict **one dependent variable (output)** using **multiple independent variables (inputs)**.
* It assumes a **linear relationship** between the inputs and the output.

---

### 🧮 **Equation**


y = m_1x_1 + m_2x_2 + \dots + m_nx_n + c


* $y$ → predicted output (e.g., Salary)
* $x_1, x_2, ..., x_n$ → input features (e.g., Age, Experience)
* $m_1, m_2, ..., m_n$ → weights/coefficients
* $c$ → intercept

---

### 🧠 **Conceptual Steps**

1. **Check if the relationship is linear**.

   * Use **graphs and correlation**.
2. If **not linear**, perform **feature selection or transformation**.
3. **Split the dataset** into training and test sets.
4. **Train the model** using the LinearRegression class.
5. Evaluate model performance using `.score()` or prediction error metrics.

---

### 🧪 **Practical Steps with Code**

#### 📥 Load Data

```python
import pandas as pd
dataset = pd.read_csv("student_data.csv")
dataset.head()
```

#### 📊 Check Data

```python
dataset.shape                # View size
dataset.isnull().sum()       # Check missing values
```

#### 📈 Visualize Data

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.pairplot(data=dataset)  # Check linear patterns visually
sns.heatmap(dataset.corr(), annot=True)  # Check correlation between features
```

#### 📂 Prepare Data

```python
x = dataset.iloc[:, :-1]     # Independent variables
y = dataset["Salary"]        # Dependent variable
```

#### 🔀 Train-Test Split

```python
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=42)
```

#### 🤖 Build & Train Model

```python
from sklearn.linear_model import LinearRegression
lr = LinearRegression()
lr.fit(x_train, y_train)
```

#### 📊 Model Evaluation

```python
lr.score(x_test, y_test)  # Accuracy score (e.g., 95%)
```

#### 📌 Model Parameters

```python
lr.coef_      # Coefficients for each input variable
lr.intercept_ # Intercept value
```

#### 🧮 Manual Prediction Formula (for 2 inputs)

Example:

```python
# y = m1 * Age + m2 * Experience + intercept
y_pred = 15.82 * Age - 2985.49 * Experience + lr.intercept_
```

#### 🔍 Predict on Test Set

```python
lr.predict(x_test)
```

---

### ✅ Key Points Summary

* Use **pairplot** and **heatmap** to validate linearity.
* Train model using `LinearRegression` after data preparation.
* Extract `coefficients` and `intercept` to form the prediction equation.
* Accuracy is evaluated using `.score(x_test, y_test)`.
